# 一箭又一箭 (Arrow Game)

## 1. 项目名称
一箭又一箭 (Arrow Game)

## 2. 游戏简介
这是一款基于 Python 和 Pygame 开发的益智类小游戏。玩家需要点击棋盘上的箭头，让箭头沿着其指示的方向飞出棋盘。如果箭头前方有其他箭头阻挡，则无法飞出并消耗一次失误机会。游戏包含多个关卡，玩家需要在失误次数用完之前，清理掉棋盘上所有的箭头。

## 3. 开发环境
- 操作系统：Windows  11 
- 编程语言：Python 3.12 及以上
- 依赖库：Pygame 2.x
- 开发工具：PyCharm / VS Code
